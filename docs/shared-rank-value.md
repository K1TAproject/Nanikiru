# 共享顺位价值模型与最终收益导出：待确认训练设置

2026-11-17。**已实现导出、特征、模型前向计算、损失与模型文件接口；没有训练，没有拟合权重，没有更改当前 v2 推荐。** 本文说明实际实现，不以先前设计清单代替已实现能力。

## 1. 实现入口与范围

- `nanikiru/training/returns.py`：A 规完整 MJAI 的最终标签、可见状态样本导出及带校验的样本读取。复用既有适配器，不重新算原谱番符支付；暂不新增 XML 收益导出入口。
- `nanikiru/analysis/rank_features.py`：固定可见特征，版本 `rank-visible-features-1`。
- `nanikiru/analysis/rank_value.py`：`RankValueModel`，版本 `shared-rank-linear-1`。

这是共享继续价值 V(I)，不是已经实现的全动作 Q(I,a)。它可读取不同决策阶段的可见状态；未知牌采样、对手概率、动作分支聚合以及在线 match_rank 调度仍未接入。未来 Q 由规则后继和 V 共同组成；不能把 V 的预测精度直接解释为新策略实战强度。

## 2. 最终收益标签

每场 `labels.jsonl` 一行，包含四家各自的：

| 字段 | 意义 |
| --- | --- |
| final_rank | 最终名次 1..4，点数相同时按初始座次排序 |
| rank_value | 负名次，固定为 -final_rank；不是学习参数 |
| final_points | 半庄结束及剩余供托归属处理后的最终得点 |
| result_points | 当前 A 规的精算点 |

精算点与现有模拟器保持同一定义：

`(最终得点 - 30000)/1000 + 名次项[20,10,-10,-20] + (一位时额外20)`。

仍坚持负期望最终名次为主目标；精算点独立输出。没有额外击飞／四位惩罚，也不把精算点加权并入主目标。

导出要求标准东一、零本场零供托、四家 25000 点，核对跨局场况、初始座次、点数与供托守恒、半庄结束条件。最后剩余供托按 A 规给第一名，再计算精算点；初始座次同点顺序不能用观察者编号代替。已由适配器处理立直扣棒和多家支付，标签层不重复扣款。

来源限定为已固定来源分区中、2023 年及以后 00a9 文件标识的 MJAI，且规则配置严格为 A 规。来源声明不等于重新裁判全部牌谱；支付仍按来源记录。

**缺失流局原因的限制：**能由零剩余摸牌和非零流局支付确认普通／流满结算时按荒牌边界处理；未指明原因的零支付流局不猜作荒牌。若因此无法确认半庄结束，导出报错并记录 failed，而非制造最终名次标签。中间缺少流局原因时，仅容许与已观测下一局场况相符的连庄／轮庄衔接。当前只实测少量来源，不声称全部 1,000 场都已通过这一新标签检查。

## 3. 样本输入与分区

`samples.jsonl` 每行有 `input`、`features`、`labels`，三者分开。只有 features／input 可以进入模型；source_id、split、观察者样本位置、最终收益均属于外部元数据／标签。

采样点包括：每局起始、本家摸牌／吃碰后、他家弃牌／杠宣告后的响应观察，以及非最终局的局末。响应观察不是合法鸣牌断言，也不是过牌动作标签。最后半庄结束状态不作为监督输入，避免靠已知最终点数做无意义预测。

选样按来源和局／座位／事件位置的 SHA256 排序截取，默认每场最多 64 条，选择不读取收益或实际选牌优劣；它是分布覆盖先导，不保证每个动作类别都有足够样本。每条 `sample_weight=1/该场实际输出条数`，同场所有样本总权重为 1，未来拟合必须采用这个权重，不能将同场重复样本当独立半庄。

沿用已有 experiment.json 中的来源分区；同场四家始终同区。样本输入经过观察规范化，只保留白名单事实，不含终局 payload、未来事件和牌山编码 ID；round_id 改为常量，不把来源哈希当特征。私有过和信息在普通 MJAI 中不能确认，继续保持缺失。

`manifest.json` 记录完整／失败状态、源身份、分区、规则、特征列、代码指纹及文件校验和。`read_samples(folder, split=...)` 拒绝失败、旧版本、内容被改动或分区不一致的数据。当前沿用的旧测试分区此前已被查看，仍是诊断集，不称全新最终测试集。

## 4. 实际特征：84 个基础量，168 维输入

每个基础量 x 均编码为 `(value, missing)` 两列：已知为 `(x,0)`，未知／本阶段不适用为 `(0,1)`。因此 0 与未知不同。缺失标志不是置信度，也不能自动推断缺失原因；阶段特征用于区分部分不适用情形。

尺度固定在代码，不使用测试集归一化。所有分母仅是数值单位，不是需要训练的奖励权重；不裁剪超出单位范围的合法值。

| 基础字段 | 个数 | 定义／尺度 |
| --- | ---: | --- |
| score_0、gap_1..3 | 4 | 本家点数／30000；本家减下家、对家、上家的点差／30000。无需再重复存四家分数与全部点差 |
| rank | 1 | 当前名次／4，含初始座次同点排序；不是最终标签 |
| round_index | 1 | 东一从 0 起的局序／11；西入仍保留实际值 |
| honba、sticks | 2 | 本场／10、供托棒数／10 |
| remaining | 1 | 剩余摸牌数／70 |
| dealer_relative、tie_order | 2 | 相对庄家位置／3；本家相对初始庄家的座次顺序／3 |
| self_turn | 1 | 当前行动者是否本家；无行动者为 0，未知行动者为缺失 |
| history_complete、public_complete | 2 | 是否完整历史／是否确认公开牌覆盖完整（0/1） |
| riichi_0..3 | 4 | 本家及按顺时针各家的立直状态（0/1／缺失） |
| melds_0..3 | 4 | 各家副露组数／4，包含暗杠组 |
| river_count_0..3 | 4 | 当前牌河保留牌数／24；被鸣走的牌不在此计数，不冒充精确巡目 |
| closed | 1 | 是否门清，暗杠不破门清 |
| regular_shanten、pairs_shanten、orphans_shanten | 3 | 普通向听／8、七对向听／8、国士向听／13；有副露时特殊形不适用；局末不计算 |
| ukeire_fraction、effective_types | 2 | 13 张等效暗手的未见进张／全部未见牌、改善牌种数／34；14 张等效时不假定先弃哪张，设缺失 |
| dora_count、red_count | 2 | 手牌＋副露的指示宝牌数／8、赤牌数／3；不计未来杠宝／里宝 |
| base_ron_min、base_ron_max | 2 | 13 张等效听牌的条件基本荣和支付范围／32000，见下文限定 |
| discard_furiten、temporary_furiten、riichi_furiten | 3 | 可确认时 0/1；私有过和仅完整 simulator 私有观察可确认，普通规范化牌谱缺失 |
| safe_tiles_all_riichi | 1 | 对全部已知立直家都属于现物的本家牌枚数／14；无立直对手时不适用 |
| pressure | 1 | 对手中已确认立直家数／3；有未知立直状态时缺失。不是放铳率 |
| gap_to_top_x_round、gap_to_last_x_round | 2 | 与最高／最低点数的差值／30000 × round_index |
| shanten_x_pressure | 1 | 归一化普通向听 × pressure |
| phase_* | 6 | await_draw / await_discard / await_response / await_kan_response / await_replacement / ended 独热标志 |
| hand_0..33 | 34 | 本家暗手 34 种牌计数／4，赤牌合入对应五，另由 red_count 保留赤身份 |

条件基本荣和特征：按已知门清／立直、指示牌和形状计算，不含一发、抢杠、海底、里宝、本场、供托或包牌；不检查实际荣和许可。默认使用普通牌面，若五的普通三枚均已在自身持牌中则用剩余赤五；不枚举所有赤／普通和牌差异。无基本役的等待取该条件下 0；自身已占四枚的形式等待不送入算分。故该特征不是最终结算，也不是预期打点。

第一版没有旧 v2 全套路线分、筋危险系数或完整手牌结构编码；不能称为已经涵盖所有麻将因素。线性模型和少量交互有明确表达限制，保留扩展空间但不预建复杂网络。

## 5. 507 个名次参数的含义

对 168 维 x，前三个名次各一行权重和截距：

`z_r = b_r + Σ_j θ[r,j] x[j]，r=1,2,3；z_4=0`

`p_r = exp(z_r) / Σ_k exp(z_k)`

- `rank_weights`：3×168＝504 个系数。某一系数表示对应特征变化对该名次相对于四位的对数概率比的影响；不是对该名次的奖励。
- `rank_bias`：3 个截距，表示全部编码值为 0 时的相对基线。零向量未必是实际牌局，不能把截距当真实开局概率。
- 第四类权重和截距固定为 0，不训练，消除所有 logit 同加一个值的冗余。
- 输出概率总和为 1，`rank_value=-(p1+2p2+3p3+4p4)`，范围 [-4,-1]。
- 系数允许正负。相关特征会影响单独系数的解释，不能从某系数大小推断因果重要性。

例如 gap_1 增加 1000 点只让该特征增加 1/30，其对名次 r 的相对 logit 影响为 θ[r,gap_1]/30，而不是直接奖励 θ 分。

## 6. 169 个精算点参数的含义

`predicted_result_points = points_bias + Σ_j points_weights[j] x[j]`

独立 168 个系数＋1 个截距。系数单位是“特征增加一个归一化单位时的预测精算点变化”。该模型输出无概率约束，是未校准时可能偏离物理合理范围的回归估计，需验证残差；不把它加到顺位分数中。

两模型共 676 个可存储系数。**这不是已有 676 个有效可拟合参数的证明。** 拟合前须按训练分区检查常量列、永远缺失列和样本覆盖，冻结没有信号的列。完整 MJAI 的私有过和状态普遍缺失，不能据此学会过和振听的收益；后续需要模拟样本补充。1000 场产生大量状态，也仍只有 1000 个来源级独立分组。

## 7. 已实现的损失与尚未启用的训练设置

`RankValueModel.loss(features, rank=..., result_points=..., l2=0.001)` 返回两个独立损失，不更新任何参数：

- `rank_nll = -log(p_真实最终名次) + λ Σθ²`。
- `points_mse = (预测精算点-真实精算点)² + λ Σψ²`。

λ 是 L2 正则强度，抑制过大系数，默认 0.001 仅是待确认起点，不是实验选出的最佳值。不惩罚截距。名次与精算点损失不相加；分别拟合，避免辅助点数目标改变主目标。未来批量目标按 sample_weight 加权平均数据损失，正则项计一次。

本轮未实现／未启动优化循环；学习率、迭代轮数、批大小、早停阈值都没有隐式运行默认值。待用户确认特征、模型与损失后，再实现受控拟合和验证流程。验证集选正则／复杂度与早停，测试集不选参；最终策略仍以独立完整半庄顺位验收。

## 8. 安全使用模型接口

```python
from nanikiru.analysis.rank_value import RankValueModel

model = RankValueModel()          # 全零初始化，trained=False
metrics = model.evaluate(request) # 返回 unavailable，不给虚假的已训练建议
```

`forward(features)` 是数值底层接口，供未来拟合与测试使用，零参数会输出均匀概率；它不代表校准结果。`evaluate` 才是带训练状态保护的预测入口。`save/load` 校验模型版本、特征列、A 规和有限系数；trained=True 必须有 provenance，但元数据存在本身不证明训练质量。`loss`、`forward`、保存和读取均不训练。

终局已知结果仍由规则或独立标签函数精确给出，不让模型回归代替事实。`evaluate` 用于继续状态，不能据 phase=ended 推断整个半庄已结束（它也可能只是局末）。
