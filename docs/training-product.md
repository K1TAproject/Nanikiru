# 多种分析方法与训练方向

更新：2026-11-13。已实现 [人工参数 v2](fixed-v2.md)、[天凤本地适配](tenhou-adapter.md)及[路线特征、离线评测与权重拟合](v2-training.md)，尚无神经网络训练或真实牌谱强度验证。另已实现[完整/不完整观察器](observation.md)，可按来源分区、逐行生成缺失变体和样本分片。

固定算法和神经网络共用[分析接口](analysis-interface.md)，可使用不同内部编码。项目目标仍包括模型训练、数据处理与接口封装；当前先完成观察数据底层，桌面对局 UI 不再作为前置条件。

## 输入与结果

- 输入必须是行动前该玩家可见的事实、必要历史和明确缺失范围。模型不得获得真实牌山、对手暗手或未来牌。
- 牌码包含赤牌身份；派生向听、资格等可以作为模型特征，但不重复成为独立事实源。
- 模型需明确能处理哪些未知模式。完整牌谱训练不自动保证摄像头漏拍或中途接入时可靠。
- 牌效评分、策略选牌概率、和牌概率、放铳概率和期望点数具有不同含义，不混为百分制正确率。
- 训练样本关联局/整场、修订、时点、规则、特征版本、实际动作和标签来源；按完整对局/整场去重划分集合。

## 数据来源建议

自己的牌谱、明确可用的研究牌谱、人工基准和未来模拟数据可用于策略学习；实际牌谱动作不默认最优。识别模型另需图像/视频和牌/区域/时序标签，不能由结构化牌谱直接替代。

已有来源调研和限制见[阶段设计](observation-data-design.md)。当前模拟器可生成可见事件，天凤适配器可导出弃牌前请求及分离标签；已做小样本外部格式验证，未下载训练集或训练模型。原 Game 已移除，不恢复旧训练链。
