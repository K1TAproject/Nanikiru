## 日常操作

默认打开“牌桌训练”。顶部保留随机新局、加载、保存、暂停/恢复和撤销；人工座位及主视角仍为实际庄家。保存依旧是包含隐藏信息的完整游戏存档。

牌桌采用深绿色分区，放大下方手牌；摸入牌独立，悬停和选中有边框反馈。点击选牌后仍需确认弃牌。玩家状态显示座位、自风、点数、庄家、立直与行动指示；河牌保留顺序，最近弃牌带边框，立直牌带“立”，被鸣走牌带叉号和目标座位。副露仍显示类别和来源。

中央牌山是按公开剩余数量绘制的余量示意，不是实际实体牌山的位置；没有展示暗牌或未知里宝。宝牌指示牌仍单独展示。

底部固定操作区保留确认弃牌、返回庄家/切到行动者、合法特殊动作菜单及执行按钮。吃碰组合、赤牌和立直的摸切/手切身份仍由核心合法动作提供。非法动作、暂停、响应收集与显式恢复行为不变。

## 训练反馈与复盘

牌桌下方保留当前可见范围内最近一次**人工**弃牌的反馈，依据记录中的 `policy=manual` 确认来源，不把旧存档的未知来源猜为人工。正常庄家视角不会被其他三家的机器人动作覆盖；切换视角后重新过滤，不能泄漏此前座位信息。

摘要包括所切牌、向听、进张及原有基础判定；非最优时列出所有并列最优牌面及指标。增加向听与同向听进张损失分开说明，强制选择单独统计；弃和提示不能把牌效损失视为综合决策错误。长摘要可以滚动查看。

“展开复盘”定位对应的逐切、听牌及役种/防守记录。机器人推进时保留当前选中的历史记录；内容未变化时不重写文本，不重置阅读位置。机器人结算只在用户仍看牌桌时自动切换结算，不抢走正在查看的复盘页。没有在刷新时重新运行分析。

“回放工具”展开或收起原有动作位置、只读回放、返回当前和回退重录。只读与暂停状态继续显示在顶部。撤销、回退和加载后的显式恢复约定保持不变。

结算页默认显示结果、连庄/供托摘要及四家点数表；点击“展开/收起番符与支付明细”查看完整原有信息，包括和牌手牌、役、番符、支付和后续局况。

## 设置与开发调试

| 功能 | 位置 |
| --- | --- |
| 四家视角、全知调试、自动理牌 | 顶部“设置” → 视角与牌面 |
| 赤宝、杠宝、场风 | 设置 → 新局规则；只影响新局 |
| 三家机器人开关、策略 | 设置 → 机器人 |
| 人工/机器人进攻与弃和 | 设置 → 评估模式；基准机器人仍禁用不适用项 |
| 可复现种子开局 | 设置 → 按种子开局 |
| 事件日志、原始 JSON | 顶部“开发 / 调试”菜单 |
| 自动化测试输出与运行按钮 | 开发 / 调试 → 自动化测试 |
| 收起辅助页面 | 开发 / 调试 → 收起调试页面，或设置页“完成 · 返回牌桌” |

技术页面默认隐藏，普通出牌不会打开。全知模式始终有黄色文字标记；退出设置页不会悄悄更改所选视角。原有 `register_action` 扩展接口仍保留在动作菜单中。

## 验证

完整回归 102 项测试通过（146.821 秒）。随后修正设置页返回按钮定位、结算明细展开和摘要排版，最终 UI 定向回归 17 项通过。新增测试覆盖辅助页默认隐藏、入口保留、人工反馈不被机器人覆盖、复盘选择保持、视角过滤与回放、小窗口操作区以及结算展开/收起。

实际检查普通牌桌、960×760 响应与设置页、1100×820 复盘和结算、全知调试，以及 Tk 字体按等效 150% 缩放的 1280×960 窗口。没有修改系统显示缩放设置，也不声称穷举所有分辨率。截图保存在 `ui-checks/training-*.png`。

界面优化不代表策略强度或分析准确率提升；既有基础牌效、役种、防守、听牌口径保持原义。
