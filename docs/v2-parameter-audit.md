# v2 参数与训练审查：严格平均顺位目标

日期：2026-11-16。用户已确认 A 规完整半庄、完整主视角可见信息、全部合法动作、平均顺位最优先；仅在证据支持平均顺位实际等效时比较平均精算点。四位、击飞、一致性均仅观察，不额外惩罚四位或奖励二位。本次授权恢复有范围的公式修改与训练，不等于推广新权重。

## 结论与范围

现有 v2 是动作启发式，不是终局顺位预测器。调度器仍拒绝 `objective=match_rank`，不会因更改实验目标而虚称已支持顺位价值计算。主评价目标是平均最终顺位；本轮拟合的直接损失仍是牌谱动作 softmax 排序损失，属于初始化。不能用一致率改善宣称实战提升。

可复用：可见请求与未知语义、合法动作检查、向听和进张、精确番符算分、部分路线距离、吃碰后的合法弃牌枚举、独立规则结算、来源分区与缓存验证、四座位批量评测。无需重写引擎或 UI。

明确需要后续补齐：

- **终局价值**：现有评分基本不利用四家点差与剩余局程。缺少后续顺位分布／价值模型，不能用一个任意点差系数冒充预期顺位。
- **和／过比较**：当前合法和牌总优先，无法表达终局和了仍四位时的合理过和。`extract` 明确排除可和牌决策；不能靠当前数据拟合解决。
- **杠**：只比较补牌前形状，未完整积分补牌、杠宝、抢杠及未来危险。应补足可见信息条件下的分支评价再训练。
- **吃碰与过**：在线枚举后续合法弃牌，但离线缓存没有保存全部分支，也没有响应标签；不能直接复用当前弃牌损失声称训练了鸣牌。
- **动作完整性**：引擎与观察候选仍需逐项核对九种九牌等可选特殊动作；用户列出的弃牌／立直／吃碰杠／过／和已能生成，但生成不等于策略充分学习。
- **路线**：断幺、役牌、对对和、混一色仍是替换距离近似，受役约束的进张未知；三种基础牌形的距离和进张可复用。
- **风险**：现物证据可复用；威胁与筋／字牌系数属于未校准指数，没有对手打点损失模型，不能解释为放铳率。

这些是结构缺口，不是本轮小规模拟合已经解决的能力。不扩充未经定义的 rank 权重，也不为缺失能力制造训练标签。

## 当前公式与修改

新公式标识：`fixed-v2-opportunity-2`。旧公式源码和权重快照保存在忽略目录 `data/external-replays/v2-rank-audit-baseline.zip`；旧报告和 `akochan-pilot-03` 均保留。拟合权重加载要求匹配公式版本，旧权重不得静默用于新公式。

记 s 为弃牌后向听，U 为进张数，N 为全部未见牌数量，q(x) 为摸到改善牌 x 后最佳保向听弃牌的下一步进张比例；完成形取 q=1。该 N 包含未知对手暗手，均匀未见抽样仅是近似，非真实牌山概率。

`S = -shanten*s + ukeire*U/N + lookahead*L + value*V/8000 + bonus*B + route*R - risk*(1+late_defense*t)*D + reserve*A - C`

- **前瞻修正**：旧 L 是在已改善条件下的 q 均值；新 `L=Σ count(x)*q(x)/N`，计入改善机会，不能让极少进张因条件质量高获得同额奖励。不是和牌概率。
- **价值去重**：未听牌时 V 不可用，B/R 作为价值代理；听牌后使用已有条件自摸打点 V，B/R 不再进入评分。条件算分缺失时保留未知，不以代理假装已算出实际收益。路线仍展示，但听牌时不重复加分。
- `R=max max(0,min(han,4)/(1+d)^2-route_speed*speed_loss/(1+d)+route_ukeire*ukeire_fraction/(1+d))`，作用于未听牌备选路线。受役约束未知进张无奖励。
- `D` 是危险指数；`t=clip((70-remaining_draws)/70,0,1)`；A 是手中对全部对手均为当前现物的牌枚数。这些定义暂保留，不声称已经校准。
- 立直成本 `C=value/8+commitment*最大威胁`；吃碰杠成本 C 为 commitment；过牌成本为零。这是同一参数跨动作复用的限制，立直押金也不是必然永久损失，需后续更合理的收益模型替换。

## 参数—公式—动作—样本—可拟合性

默认值仍是人工起点，本轮没有凭四场试跑修改默认数值。新拟合产物仅候选；旧权重在新公式下也不是原策略。

| 参数（默认） | 直接作用 | 在线动作 | 当前样本与拟合判断 |
| --- | --- | --- | --- |
| shanten (4) | -s | 弃牌、立直、鸣牌后分支、过 | 固定作评分尺度；不同时搜索全局尺度 |
| ukeire (2) | U/N | 同上 | 可拟合；要求库存已知且候选有进张差异 |
| lookahead (3) | 无条件改善质量 L | 同上 | 修正后重新提取；可拟合，不用旧条件质量缓存 |
| value (1.5) | 听牌条件打点 /8000；立直成本 -1/8 | 听牌弃牌、立直及分支 | 可拟合，但候选听牌／立直覆盖是关键；不是一般未听牌打点预测 |
| bonus (.25) | 未听牌所保留暗手宝牌数 B | 弃牌与后续分支 | 可拟合；听牌去重，鸣牌转移宝牌到副露的价值仍有近似缺陷 |
| risk (7) | -(1+late_defense*t)*D | 实际弃牌及鸣牌后弃牌 | 可拟合已有指数的重视程度；不同时校准指数内部系数 |
| reserve (.3) | +A | 各手牌分支 | 可拟合；存在与形状／风险相关性，不能由非零权重证明独立价值 |
| late_defense (.8) | -risk*t*D | 同 risk | 可拟合，但 risk=0 时失去作用；需联合检查 |
| route (2) | 未听牌路线潜力 R | 各手牌分支 | 可拟合，受路线近似能力约束 |
| route_speed (1) | 路线速度损失惩罚 | 同 route | 可拟合；route=0 或所有路线被截断时无信号 |
| route_ukeire (1) | 路线进张奖励 | 同 route | 仅有已知路线进张时有效；与普通进张项可能相关 |
| commitment (.5) | 立直锁手及鸣牌成本 | 立直、吃碰杠 | 只能通过立直分支拟合本轮数值；不能称鸣牌成本已获验证 |

新增 `parameter_coverage`：只读取训练分区，通过有限参数扰动统计候选间分差发生变化的决策数与动作种类；所有候选共同平移不算信号。请求拟合但无信号的参数冻结并报告。该计数不是充分样本量、可辨识性或因果重要性的证明。非线性交互会受扰动点影响。

搜索仍为两轮坐标搜索，固定 shanten，尝试其余 11 项。候选网格增加默认值的半倍、两倍，以免参数被选成零后只能回到默认值。训练损失搜索、验证损失挑整组；测试不参与选择。

## 本轮实验方案

1. 重用已核对 A 规的第一轮 1000 场可见请求导出，不重下载、不重复导入原始牌谱；不复用旧特征。每份导出记录 SHA256，保持 source_id 与原 802/118/80 分区。

4. 旧测试集已经被查看，本轮只作重用诊断集，不称新鲜最终测试。尚未运行对战就不认定新权重优于旧版，也不改任何 UI 默认加载路径。
