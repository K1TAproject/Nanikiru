# 顺位评价与动作分支契约 v1

日期：2026-11-17。状态：本轮固定的开发契约；不是已经实现的新分析器。现有 fixed-v2 仍使用启发分并拒绝 `objective=match_rank`。本文件不改变 A 规、当前权重或运行默认策略。

后续实现：[合法候选与条件后继分支](successor-branches.md)。已补九种九牌候选、鸣后全部弃牌输出，以及离线模拟世界的完整响应枚举；尚未实现可见信息假设世界采样与统一顺位预测。用户允许精算点难以定义时使用最终得点；A 规已有定义，仍优先沿用精算点。

## 1. 评价单位与边界

- 主目标 `rank_value=-Σ(r*P(final_rank=r)), r=1..4`，范围 [-4,-1]，越大越好。不增加击飞、四位惩罚或二位奖励。
- `settlement_value=E[最终精算点]` 独立保存，不与主目标加权相加。版本晋级只有独立评测支持平均顺位实际等效，才参考精算点；不显著不等于等效。
- 动作层优先比较 rank_value；数学上相同的值可用 settlement_value 及固定次序打破平局。统计“实际等效区间”是实验选择规则，不是每个动作随意设的风险阈值。
- 每个值必须附 `status`（available/conditional/unavailable/not_applicable）、`basis`（exact/estimate/heuristic）、方法版本、假设、覆盖范围。缺值为 None，不是 0。启发评分不能冒充负期望名次。
- 终局且完整支付／同点顺序已确定，按 A 规计算 exact 最终名次。局末但半庄未结束，用局间继续价值；局内未结束还需局内状态评价或模拟连接。局间价值模型不能直接评价尚未结算的任意弃牌。
- 合法和牌也不总能在声明前得到唯一精确终局值：里宝未知、其他同时和家、供托归属等可能造成分支。只有条件结果确定的子分支能标 exact，聚合结果仍可为 estimate。

## 2. 输入与隔离

沿用 AnalysisRequest 的 position、history、coverage、state_version、rules；仅可使用决策当时观察者可见信息。新增规划内部数据不得绕过该边界。

局间价值所需：四家点数、观察者、庄家、场风局数、本场、供托、同点排序所需初始座次以及 A 规终止条件。局内还需自身手牌／副露、公开牌、立直、剩余摸牌、行动与响应阶段及私有振听事实。未知资格继续 unknown，不根据完整公开历史捏造非振听。

原始全知牌谱仅由适配器用于重建每位观察者当时的自身暗手、验证库存和生成分离标签。绝不把其他玩家的暗手、下一张真实牌、终局数据或含来源语义的实体 ID 送入策略。

## 3. 最小分支结构（设计，不预建框架）

每个根候选绑定 `state_version + Action`，采用既有 Action 类型；分支本身是内部计算产物，不写回权威 RoundRecord。

| 节点 | 必须包含的语义 |
| --- | --- |
| decision | 行动者、合法候选、当前可见信息；max 只能在实际获得这些信息后执行 |
| response | 响应机会、优先级与待确认响应；他人响应是未知行为，不由本家控制 |
| chance | 可能结果、概率来源／采样方案、可复现的计算随机种子；不得使用真实局面隐藏种子 |
| leaf | 状态边界（局内截断／局末／半庄末）、value、方法、假设与缺失信息 |

所有节点须维护库存、摸打阶段、供托、振听、立直、剩余牌和规则时序；使用纯计算或隔离副本，不修改调用者状态。不对“不可能发生的分支”分配概率。

机会节点加权期望；自身决策节点在可见信息允许区分的后续状态中选最优；对手决策须由明确的对手模型／策略产生。不能对每个暗手采样世界用全知最优决策后平均，避免虚构玩家知道隐藏牌。

分支覆盖记录应区分：规则分支是否枚举完整、随机结果是否采样、是否达到计算预算、继续策略版本与估计误差。不得把抽样未命中当作分支概率为零。未评价候选不标 forbidden；统一价值尚未覆盖时不得与旧启发分混排。旧 v2 仅作为明确标识的旧方法继续存在。

## 4. 各动作展开

| 动作 | 顺序及必要处理 |
| --- | --- |
| 弃牌 | 弃牌→响应优先级（含多家荣和／三家流局）→鸣牌／正常摸牌／终局→继续价值 |
| 立直 | 宣言＋弃牌→响应；宣言牌荣和则不成立／不扣棒；成立后扣棒、锁手与一发条件按规则处理 |
| 吃／碰 | 提交响应→处理竞争；若成立，移动牌与更新副露→全部合法弃牌（食替）→继续分支；提交不等于必定成立 |
| 明／暗／加杠 | 声明→可抢杠响应→成立及四杠等终止检查→按规则补牌与翻宝时序→和牌／合法弃牌→继续；区分三种杠 |
| 过 | 响应窗中拒绝对应许可；若合法荣和未取，正确更新临时／立直振听；无荣和许可时不虚构见逃 |
| 荣和 | 校验真实资格→同时响应／终局规则→支付供托→局末或半庄末价值 |
| 自摸 | 校验资格→含未知里宝等必要随机分支→支付→继续／终局；不自摸是后续弃牌或杠等选择，不凭空增加模拟器不支持的 pass 动作 |
| 特殊合法动作 | 九种九牌等须与引擎许可核对并纳入；规则自动事件不是玩家可选择动作 |

里宝、新杠宝、补牌、抢杠概率均来自明确估计，不能偷看原谱未来。先使用真实未来结果决定杠，再把输入遮住，仍然属于泄漏。

## 5. 标签契约：事实、推断、遮蔽分离

训练样本身份继续为来源／局／观察者／事件前缀；同源四家及各种变体始终同区。标签只能进入训练侧。

设计标签字段：`label_kind`、`action`（无唯一动作时 None）、`excluded_actions`、`evidence`（解决响应窗的原始行号／事件）、`censor_reason`、`outcome`。输入在响应触发点截止；后续解决事件仅为标签证据，不进入 input/history。

| label_kind | 条件 | 可用于什么 |
| --- | --- | --- |
| observed_action | 来源明确记录成立动作且与当时候选匹配 | 该动作正例；吃碰后弃牌另取自己的决策样本 |
| inferred_no_meld | 完整顺序中，自己确有合法吃碰杠机会，响应窗随后无人鸣和、正常进入下一家摸牌 | 当时合法鸣牌集合的负例；不直接标为全动作 pass，更不证明放弃合法荣和 |
| censored | 别人鸣牌／和牌、途中流局等使本家原始响应意图不可确认 | 保留计数／来源，不作硬 pass 监督；初版保守排除整个窗的未观测者 |
| unknown | 手牌、历史、资格或响应边界不足 | 不作确定行为标签；不伪造负例 |
| forced | 无真实可选鸣牌机会等 | 单独统计，不以大量无机会窗提高“过牌准确率” |

`inferred_no_meld` 表达“不选这些合法鸣牌”，不声称点了过牌按钮，也不区分超时／取消自动鸣牌等行为原因。对已成立鸣牌者，可以学习已观测选择；若同时其他玩家响应，未成立者意图仍不可见。

针对吃碰杠时机，可以先训练“是否选择鸣牌”及“鸣牌中的具体选择”，使用正例和可靠负例。若未来用全动作统一损失，部分标签只能约束其证据覆盖的动作子集，不能把未知荣和候选强行赋零。只用鸣牌正例能学到已鸣场景中的选择，但无法可靠学到何时不鸣；采样若改变正负比例须记录／校正，评测使用自然分布并按动作报告。

## 6. 离线分支与收益训练

缓存应保留与参数无关的分支事实／特征，或可重建的可见状态。吃碰后所有合法弃牌在每次参数试值下重新评分选优；杠使用固定、可复现且与标签独立的采样分支。不能只缓存旧权重下的最好后续。

行为标签与收益标签分开：牌谱只观察实际行动及后续结果；不能给未选分支填实际牌谱最终收益。局间模型可以学习真实局末状态到最终名次，但它反映来源玩家策略的分布，需在模拟对战上校准／检验。未知反事实动作价值依赖模型或独立模拟，不由日志凭空产生。

## 7. 实施前验收门槛

1. 全合法动作集合与 A 规引擎逐项对照，包括特殊动作和响应竞争。
2. 反事实分支不污染输入，公开/暗牌库存、立直押金、振听与杠时序回归通过。
3. 相同观察而仅修改隐藏真实牌山／对手暗手，不应改变相同计算随机种子下的策略结果。
4. 同点名次与终局条件精确测试；未知里宝不误标 exact；精算点不混入主目标加权。
5. 正例、可靠鸣牌负例、遮蔽与未知测试；“别人碰了”不产生本家 pass；没有机会的窗不充当可选过牌样本。
6. 参数改变能重新选择后续弃牌；离线重评分与在线计算一致。
7. 按来源隔离数据，固定公式、策略、采样版本，完成小规模覆盖校验后才扩大正式训练。

## 8. 本轮交付边界

契约固定不等于实现全部分支或价值模型。本轮只新增只读覆盖审计工具，读取既有牌谱并复用现有合法候选；不训练、不修改分析器接口／权重／规则。实测数据支持程度见 [响应数据审查](response-data-audit.md)。
