## 可训练什么，缺什么

| 能力 | 现有数据支持 | 仍需开发或补充 |
| --- | --- | --- |
| 弃牌／立直模仿 | 已有导出与拟合链 | 新公式版本下重建特征；不要将模仿收益当作顺位收益 |
| 吃碰是否值得选择 | 成立正例＋可重建的可靠不鸣负例 | 响应样本导出、部分标签损失、自然分布评测、竞争遮蔽统计 |
| 吃碰后的弃牌 | 实际弃牌可观测，全部合法后续可由规则生成 | 每轮权重都重新比较所有后续；未选后续无真实收益标签 |
| 杠时机 | 三种杠都有实际正例，但明杠仅 68 次 | 稀疏性控制、规则分支测试及独立模拟；不能只靠正例拟合完整杠价值 |
| 和牌与过和比较 | 实际和牌与支付可观测 | 私有振听／过和历史未必可确认；需可靠推断或带显式响应的模拟数据 |
| 局末到最终顺位价值 | 完整半庄与支付支持恢复事实结果 | 最终点数／同点规则校验、单独收益标签导出；只代表来源策略下的继续结果 |
| 任意未选动作的顺位价值 | 没有直接反事实标签 | 可见信息约束的分支模拟或转移／继续价值模型，不得借用原谱未来当作所有动作的结果 |

## 为什么缺少显式 pass 仍可学习

例如上家打出 3p，观察者当时有 4p、5p，满足吃牌资格且有合法后续弃牌。如果完整事件顺序显示无人鸣和，正常进入下一家摸牌，则可确认其没有选择这次吃牌；不需要日志显式记录“点过”。它是针对已确认鸣牌选项的负例，不能扩展成“他也放弃了合法荣和”。

若另一个玩家碰了这张牌，本家是否曾请求吃不可知。初版将未观测者保守标为遮蔽，不硬标 pass。若本家没有合法鸣牌选项，则该窗不能充当“明智地不鸣”的样本。

只用成立鸣牌正例，可以学习高手在什么形状下鸣、如何选择吃的组合及鸣后弃牌，但无法可靠判断不鸣的边界，容易偏向过度鸣牌。现有完整原始数据足以开始“正例＋可靠负例”的时机学习；竞争导致的选择性缺失仍存在，最终须以独立完整半庄对战评价。
