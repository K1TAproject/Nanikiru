# 听牌质量与合法和牌张分析

2026-09-18。本阶段增加分析、记录与展示，不调整任何机器人选择、基础牌效排序、逐切统计或攻守策略。

## 接口与信息边界

`nanikiru.tenpai.analyze_tenpai(observation, legal_discards)` 接收行动前玩家观察及核心提供的合法 `Discard`，返回 `tenpai-v1-mahjong-2.0.0`。不接收 Game、牌山、种子或对手暗手，不修改输入或真实局面。

`Game.observe(seat)` 新增 `own_status`，仅包含该观察者自己的 `temporary_furiten`、`riichi_furiten`、`double_riichi`。没有其他玩家的私有振听数组；`players[].riichi` 仍仅表示已成立立直。新字段不参与机器人排序。

基础牌效仍由 `efficiency.analyze_discards` 计算；新模块只评估切后 0 向听的候选，其他候选为 `not_applicable`。完成形使用 `scoring.waits` 和固定版本 mahjong 库，按暗手、副露适用条件处理普通形、七对子与国士。全持牌已含四枚的牌种不能再加入第五枚；因此形式向听为 0 的局面也可能没有物理可完成的等待。

可见牌枚举复用 `efficiency.visible_tiles`，基础的 `visible_counts` 也使用该入口。自家暗手和摸入牌、所有副露、未被鸣走的河牌、公开指示牌各计一次。拟弃牌已经在可见信息中，不会回到未见库存。被鸣走的牌只在副露计数，但仍属于舍牌振听历史。

## 条件与口径

- 时点为候选弃牌之后，评估以后出现该牌时的普通荣和或普通自摸条件；不是当前响应窗口的动作许可，不承诺在余牌耗尽后仍有摸牌机会。
- 使用当前场风、自风、门清/副露、已成立立直、已知双立直、当前公开宝牌及规则开关。立直宣言的弃牌仍基于宣言前观察，不提前增加立直役。
- 不假设未来立直、一发、里宝、海底、河底、岭上、抢杠、天和或地和；只使用当前已经公开的指示牌，不预测未来杠宝。关闭赤宝仍保留赤五身份。
- 完成形分别调用 `scoring.evaluate` 计算荣和与自摸。有役条件、条件番符点数和振听限制分开保存。门清自摸可以有役，而相同牌形普通荣和无役；宝牌本身不是役。
- 点数为算分库的基础支付：荣和由放铳者支付 `cost.main`；庄家自摸每家付 `main`；闲家自摸庄家付 `main`、另外两家各付 `additional`。不含本场、供托、责任支付，不是实际结算或期望收益。
- 赤五与普通五合并判断牌形，实体库存按每门一赤、三普通五分别扣除，并分别算分。已见尽的等待仍展示，未见为零；若某实体已全部在自身手牌/副露中，则不生成不可能的额外同身份牌。
- 未见枚数包含可能位于对手暗手、保留区等处的牌，不能称为真实活牌山余量，也不换算成和牌概率。

## 振听与数据字段

核心与分析共用 `scoring.ron_restrictions`。完整等待集合与自家牌河（包括拟弃牌）相交时，全部等待都不能荣和；不是只封锁曾打出的牌。临时振听与立直后振听分别保存，二者均不禁止自摸。

返回顶层包含 `version`、`player`、`limited`、`assumptions`、`candidates`。候选含：

| 字段 | 含义 |
| --- | --- |
| discard / shanten / status | 合法弃牌身份、切后向听、适用与否 |
| waits | 按牌种的理论等待、合计未见、赤/普通实体 variants |
| shape_wait_types / shape_unseen | 理论等待种数及未见枚数 |
| available_wait_types | 尚有未见牌的等待种数 |
| yaku_unseen.ron / tsumo | 对应条件下有役的未见枚数，尚未扣振听，不能称为合法荣和余量 |
| ron_restrictions / ron_state | 舍牌、临时、立直后振听或未知；permitted / blocked / unknown |
| ron_state_after_own_draw | 仅解除临时振听后的限制；假定等待不变且期间无新见逃，不预测实际未来局面 |
| variants[].ron / tsumo | has_yaku、value（番符、役、基础支付）、score_status、permission |

`permission` 为 `no_yaku`、`blocked`、`unknown` 或 `permitted`；最后一种仅代表所列假设下的条件允许，不表示等待尚有未见牌或当前有合法响应。即便振听，仍保存有役完成形的条件点数。

输入缺少自身临时/立直振听字段时为未知，`limited=true`。已知舍牌振听可在其他状态未知时确定禁止荣和。双立直状态缺失且已立直时，条件点数明确标为仅按普通立直计算，不冒充完整已知打点。

## 记录、界面与兼容

新弃牌（含立直宣言中的弃牌）成功后，现有 `review_records` 中增加独立 `tenpai` 字段，共享同一行动前 `observation`、`actual_action` 和实际选择 `comparison.selected.discard`。失败动作不写入分析；原 `analysis` 和统计保持原义。

图形窗口新增“听牌质量”页，按当前视角和回放位置列出记录，可用下拉框选择逐切结果。各候选展示实际选择、等待、未见、荣和限制及条件算分。玩家视角只显示自身记录，全知调试可看四家。

Game 保存为 v6，加载 v2/v3/v4/v5/v6。加载重放动作、重算并核对已经保存的分析；不支持的分析版本或结果不一致会拒绝。旧记录没有 `own_status`/`tenpai` 时保留原有缺失，不使用后来状态补写历史；界面提示“分析受限，振听未知”。旧 v2 的基础分析仍按原流程补建，但不补猜新的自身状态。混合旧、新记录再次保存加载后仍保持各自字段。撤销、回退、分支和只读回放沿用原记录生命周期，不保留撤销分支的分析。

## 固定牌例与验证

`tests/test_tenpai.py` 包括：

- `123万 123筒 123索 中中 45索`，切额外九万后等待三索/六索，合计未见 7 枚；打过任一等待则全部荣和受限。若额外摸入六索并切出，未见变为 6 枚且形成舍牌振听。
- `123万 456筒 789索 南南 46万`：五万嵌张完成形普通荣和无役，门清自摸有役；赤五增加赤宝，关闭赤宝后两种五的条件点数一致。开门后普通自摸也不能凭自摸获得役。
- 七对子单骑、国士十三面、吃/明杠/暗杠手牌张数、第五张排除、鸣走河牌和指示牌计数、已见尽等待、临时振听解除、立直后振听、未知状态、立直宣言前分析。
- 条件算分与核心普通荣和对照、隐藏牌山/对手暗手独立性、输入不变、撤销分支、旧存档保留和分析篡改拒绝；界面测试覆盖视角隔离、回放与旧记录提示。

没有新增综合评分、立直/默听决策、两步进张、自动攻守、训练、导出或连续多局。

实际验证：项目 Python 3.11.4 下完整 100 项 unittest 测试通过（148.206 秒）。检查了 1100×820 的真实 Tk 窗口，截图为 `ui-checks/tenpai-review.png`；候选内容可滚动浏览，历史选择和底部操作保持可用。
