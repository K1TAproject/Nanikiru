# v2 进攻路线与动作比较

更新：2026-11-13。已实现，沿用 `fixed-v2` 的 `recommend` 任务。无需新增请求类型；v1 和原单局面 `test_ui/` 不变。

## 输入与职责

输入仍是玩家可见的 `AnalysisRequest`：本人手牌和副露、公开牌、场况、行动阶段、待响应事件、本人摸牌上下文、历史覆盖和入口立直事实。分析不访问模拟器真实暗手、牌山、种子或未来事件。

`rules/visible_actions.py` 根据可见事实生成许可；`analysis/routes.py` 计算路线；`analysis/action_policy.py` 构造不修改原输入的假设分支，调用已有 v2 评分；调度器统一返回结果。模拟器仍独立裁定执行是否合法，鸣牌意愿可能被其他人的更高优先级动作打断。

## 已实现路线

每个弃牌后或等待摸牌的 13 张等价牌形，输出 `metrics.routes`：

- 一般形、七对子、国士：牌形向听加一作为成形距离；有副露时不评价七对、国士。
- 门前立直、断幺、役牌、对对和、各花色混一色：按现有牌形、需替换牌和副露约束给出启发式距离。食断开关生效；役牌对子若已无剩余第三枚则不列为路线。
- `preferred` 是当前潜力最高的路线，`potential` 现包含速度损失和路线专用进张，公式及字段见[路线与拟合](v2-training.md)。这是备选路线，不能相加当作复合役番数；也不是实际完成所需摸牌次数、和牌率或期望打点。

旧公式只比较番数与距离，可能使相距很远的七对子超过较近的普通形。当前已加入速度损失和可计算的路线进张，摘要仍称“役种潜力参考”，不把 `preferred` 解释成多步最优路线。已实现独立本地牌谱评测和参数拟合；真实牌谱拟合与模拟对战强度验证尚未完成。

新增人工参数 `route=2.0`，把路线潜力纳入原综合分。尚未做全役种搜索、路线间转换的多步搜索或长期收益预测。原改善牌前瞻仍只比较下一次改善后的牌形质量。

## 动作分支

| 动作 | 本轮评价方式 |
| --- | --- |
| 弃牌 | 原有速度、进张、条件打点、危险度，加上路线潜力 |
| 立直切牌 | 与同一张默听弃牌分开列出；假设立直成立后计算条件打点，扣供托成本代理和锁手威胁代价，不预测里宝、一发 |
| 吃／碰 | 构造副露后的手牌，枚举符合食替约束的弃牌，取综合分最优者；记录 `follow_up_discard` |
| 大明杠／暗杠／加杠 | 评价杠后、岭上摸牌前的牌形及未见牌改善前瞻；不预测新宝牌、抢杠损失或四杠散了收益 |
| 不鸣／不和 | 评价保持现有手牌的分支；当前不出牌的即时放铳风险记零，不代表后续安全 |
| 自摸／荣和 | 检查牌形、役与已知资格；合法和牌优先于其他动作。算分是已确认条件下的结果，不代替最终结算 |

新增 `commitment=0.5`，作为副露、杠及立直锁手的人工代价。进攻排序排除危险度和安全牌储备项；防守排序按即时风险；综合排序使用全部项。吃碰分支的后续弃牌统一按综合分选择，尚未为每种策略分别搜索。九种九牌主动流局决策、名次目标、终局策略与多步最优攻守切换未实现；弃和通过防守候选表达，不是单独的规则动作。

## 输出契约

- `candidates` 现在允许同一张牌同时出现 `discard` 和 `riichi`；也允许 `pass/ron/tsumo` 等没有 `tile_ids` 的动作。消费端按完整 Action 区分，不能用第一张牌作所有动作的唯一键。
- `situation.discard_ranking` 和原 `attack_ranking/defense_ranking/overall_ranking` 保留为弃牌比较；新增 `attack_action_ranking/defense_action_ranking/overall_action_ranking`，`action_ranking` 指向综合动作排序。
- `recommendations.attack/defense/overall` 现在返回各策略下已确认 **allowed** 的最佳动作，并非仅弃牌。条件偏好可包含 unknown；如果存在资格尚不明确的可能和牌，暂不发可执行推荐，避免诱导漏和。
- `metrics.action_evaluation` 说明分支假设、代价或鸣牌后弃牌；`policy_score.details.contributions` 可核对总分。和牌候选仅有和牌相关指标，不保证具有弃牌向听、进张等字段。
- `target_id` 引用当前观察记录内的事件编号。外部执行器必须按来源映射到实际事件，不能把观察编号当作模拟器全局编号直接执行。

手牌不全时不虚构动作；其他条件未知时保留 unknown。中途接入可计算路线和条件偏好，但不能自动证明非振听。当前只有保留本人私有过和事实的完整 `sim_*` 历史可证明未发生过和；天凤及规范化 `observed_*` 历史即使从开局开始，也不能证明未过和。已知自身弃牌包含等待牌时仍能确认振听。后续需要专门的资格事实契约，不能以空历史冒充没有发生过。

## 查看与验证

运行 `python -m simulator_ui` 或 `python -m event_ui`，选择 `fixed-v2`；统一摘要显示动作推荐、路线和鸣牌后计划，输入／结果 JSON 显示完整指标。`python -m examples.analyze_v2 --json` 可在命令行查看。原单局面工具未改动。

批量观察审计继续保留按弃牌的 `candidate_statuses`，新增 `action_candidates`，避免空牌 ID 或立直覆盖弃牌。现有数据集仍是弃牌／立直标签集，本次没有宣称已具备吃碰杠和牌的全动作训练标签。

新增自动化场景覆盖立直与默听分离、不修改输入、吃碰食替、三类杠、抢杠、和牌优先、缺失过和历史、路线及食断开关；候选许可与模拟器同场景合法动作核对。启发式分数尚未经实战强度或统计校准。
