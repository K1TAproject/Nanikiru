# 全动作统一顺位价值：建议方案 v1

2026-11-17。状态：设计建议，尚未实施，不代表 fixed-v2 已支持 match_rank。用户已确认目标：完整 A 规半庄，严格平均最终顺位优先，同等时精算点次之。沿用 A 规精算点，同时保留最终得点。本文不启动训练、不推广权重。

## 1. 固定收益，训练预测机制

I 表示决策当时的玩家可见信息与已确认私有事实，a 为合法动作。固定后续本家策略 π、对手组合 μ 后：

`Q_rank(I,a;π,μ) = -Σ(r * P(R_final=r | I,先采取a,随后π,μ)), r=1..4`

`Q_points(I,a;π,μ) = E[最终精算点 | 同样条件]`

先最大化 Q_rank，数学上相同时再比较 Q_points，最后用固定次序稳定打破平局。不额外奖励二位、惩罚四位／击飞；不加动作种类奖励。统计实际等效只用于实验晋级，不直接变成动作层任意 epsilon。估计不确定并不证明顺位相同；不能因为差距小就擅自用精算点覆盖主指标。

所有动作共用收益定义。无逐步点数奖励与折扣（γ=1），避免重复计入得点或改变长短期偏好。动作不必使用同一条状态变换公式，但其结果必须落到相同收益单位。终局精确结算作为边界条件，不要求回归器拟合已经已知的结果。

## 2. 共享继续价值与分支聚合

以现有规则分支为基础，定义统一截断边界：本家下一个可决策观察点、局末或半庄末。预算截断必须标记类型，不伪称自然边界。根动作后推进响应、随机事件及必要的对手动作，直到该边界；每个样本只将此时本家可见信息送入继续价值模型。

`Q_rank(I,a) ≈ Σ_b w_b * V_rank(I_b)`

`V_rank(I_b) = -Σ_r r * p_theta(r | features(I_b))`

半庄末的 V 由规则直接取负最终名次；非终局由 θ 预测。Q_points 用相同分支权重和独立点数模型。权重来自可见信息约束的假设世界与固定对手策略，不来自旧启发分；响应组合不能默认等概率，也不能由本家选最有利的对手响应。

若边界上本家继续行动，V 的标签对应固定 π 的继续结果。不能一边把 V 当作固定策略价值，一边不加说明地解释成所有未来最优策略价值。策略迭代后更新数据／模型版本，避免将旧策略分布误作当前策略。

同一决策比较候选时采用共同假设世界样本降低方差；每个假设世界必须与同一个可见输入一致，而不是复用宿主真实世界。后续决策只依据当时能看到的内容；不可每个世界按其真实隐藏牌全知选优后平均。

## 3. 第一版价值模型及参数

先用小型、可审计的带正则多分类回归，而非直接进入深度神经网络。对固定特征向量 φ：

`z_r = b_r + θ_r·φ, p_r = exp(z_r)/Σ_k exp(z_k)`

固定第四类 logit 为 0 消除共同平移冗余，训练其余三组系数；p 非负且总和为 1，V 必在 [-4,-1]。参数不统一限制非负：相关特征、交互和参考类决定符号，单一系数不能解释为因果影响。

| 特征组 | 最小候选字段 | 主要覆盖 |
| --- | --- | --- |
| 半庄场况 | 四家相对点差、当前名次、局数、庄家／初始座次、本场供托、终止规则相关场况 | 全动作，尤其流局、过和、终盘取舍 |
| 自身形状 | 普通／七对／国士向听、各自进张比例、等待质量、门清／副露结构 | 弃牌、鸣牌、过、杠后 |
| 得点条件 | 已确定役／宝牌、条件和牌支付、打点未计算标志 | 弃牌、立直、和牌、鸣牌 |
| 对手公开压力 | 各家立直、副露、牌河事实、现物／筋等特征及观察覆盖 | 推拉与保留安全牌 |
| 约束与阶段 | 自身立直、临时／立直／舍牌振听、响应／摸打／局末阶段、剩余摸牌 | 过和、立直、各类响应 |
| 少量预先指定交互 | 点差×剩余局程、立直×手牌阶段、压力×向听、门清×路线 | 防止用一个固定“速度权重”表达所有场况 |

所有未计算或未知字段带独立缺失标志；不把未知当 0。不同状态阶段使用有效性掩码／阶段特征，局末不能填入不存在的手牌向听。特征变换、归一化、截点只由训练集确定；缺乏样本覆盖的交互不拟合。第一版不要同时引入几十项路线规则和大规模交互。

点数继续模型独立拟合 `m_psi(φ)`，可先用正则线性回归，以实际精算点为标签；主、次模型分开训练，避免辅助损失权重暗中改变主目标。所有模型保持同一来源分区。若线性模型的验证误差或校准不足，再由证据决定引入样条／更强模型，不先堆参数。

## 4. 参数的职责与旧能力迁移

| 参数／配置 | 如何得到 | 不该混淆的事项 |
| --- | --- | --- |
| θ：最终名次分布系数 | 有可见状态与最终名次的样本监督训练 | 不是原 risk/value 权重换名 |
| ψ：精算点继续值系数 | 独立收益回归 | 不与主收益加权混合 |
| β：对手响应／继续行为模型（后续） | 正例、可靠部分负例与明确遮蔽标签；也可先用冻结对手策略 | 某张牌合法可和不代表对手一定选择和 |
| η：隐藏状态推断（后续） | 有标签的状态预测／规则约束采样，必须独立验证 | 均匀未见牌近似不是已学到的真实牌山分布 |
| 正则、特征复杂度、样本数／推进预算 | 验证集与运行预算确定并记录 | 计算预算不是麻将收益权重 |

向听、进张、精确算分、可见库存和现物证据复用为事实／特征。旧路线和危险指数可作为明确标记的初始特征，并与其基础事实消融比较；不当作校准概率。旧 commitment、强制和牌优先、任意立直押金惩罚不进入新目标。押金、开门、锁手、振听、宝牌变化通过真实分支状态与继续值影响结果，不能重复再扣一次启发成本。旧 v2 保留为对照和可能的冻结继续策略。

## 5. 各动作怎么比较

| 动作 | 统一评价中真正改变的东西 |
| --- | --- |
| 弃牌 | 公开弃牌、被荣和／被鸣／无人响应后的状态分布 |
| 立直 | 宣言牌响应、成立扣棒、锁手、一发／里宝条件及后续状态 |
| 吃碰 | 竞争成立概率、开门和形状变化、后续所有合法弃牌 |
| 三种杠 | 抢杠、完成、补牌／翻宝、后续自摸或弃牌等分布 |
| 过 | 其他人的响应、继续摸打；放弃合法荣和的振听状态 |
| 荣和／自摸 | 支付与供托、同时和牌和未知里宝，之后局末／半庄末 |
| 九种九牌 | 流局后的本场、庄家、点数和继续价值，对比继续打 |
| 促成四风／四立直 | 正常弃牌／立直分支中的自动流局，不另造动作 |
| 弃和 | 由所有合法动作的 Q 比较体现；不另加“防守奖励” |

鸣后弃牌只有在实际观察到对应信息时才能选。多层搜索若选后续最优动作，须使用同一可见信息下聚合后的估计，不能对隐藏世界分别取全知最大值。

## 6. 训练目标与数据阶段

第一阶段：先导继续价值监督。每个可见状态的标签是该来源半庄最终名次 R；主损失 `-log p_theta(R|φ) + λ||θ||²`，点数模型使用独立回归损失。按半庄分区并限制／加权同场样本数，避免长场或重复状态主导。终局未来仅进标签，不能进入输入。按阶段和关键动作后状态检查覆盖、校准、负对数似然、概率误差及负期望名次预测误差。

牌谱阶段 V 反映来源玩家的混合继续策略，只作初始化，不证明候选动作的因果优劣。只对已执行动作套用最终标签再直接比较所有未选动作，会受选择偏差和覆盖缺失影响；不能声称由此得到可靠反事实 Q。鸣牌行为学习可辅助初始化 β，但与最终收益损失分开。

第二阶段：固定本家继续策略 π、对手组合 μ，用模拟数据校准 V，并在合法状态及动作后状态上补足九种九牌、过和、杠等稀疏覆盖。选择初始模拟局面／根动作不得偷看未来收益。可见信息采样、分支聚合上线后，用相同假设世界比较动作；需要已实现且通过隔离测试的采样器，不能拿真实牌谱未来替代。

第三阶段：独立完整半庄对战评测；按平均最终顺位验收，实际等效时比较精算点。akochan 首先作为冻结对手；如果其开发对局用于调参／训练，相应种子和结果即为开发数据，另留最终测试种子和其他对手组合。再进行有限策略迭代，不立即启动大规模强化学习。

## 7. 推荐实施顺序及验收

1. 最终收益标签导出与特征表冻结：最终支付／同点顺序校验；无未来信息；全部来源及观察者同区。
2. 实现 θ、ψ 与小样本监督：概率合法、缺失语义正确、终局不回归、训练进度与验证指标可复现。第一版含局内及局末阶段，不能仅做局间模型后冒充动作估值。
3. 响应样本导出／行为模型与一致假设世界采样：规则合法、库存和历史约束、隐藏宿主状态隔离、条件概率／覆盖可解释。
4. 新方法接入所有根动作及统一 Q：未知或预算不足明确降级；禁用旧硬排序与旧任意成本，但不影响保留的旧方法。
5. 全动作稀疏场景测试、模拟继续值校准及独立半庄对战，然后决定是否扩大正式拟合。

无需再由用户选择任意 risk/commitment 权重；这些应由目标、状态事实与数据共同决定。但模型具体参数数目必须在特征表和覆盖审查完成后冻结，不能现在宣称参数已全面且可辨识。
