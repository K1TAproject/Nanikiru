# 连续单局测试 UI

```powershell
.\.venv\Scripts\python.exe -m simulator_ui
# 或在 IDE 运行根目录 run_simulator_ui.py
```

这是新建的独立窗口程序，不替换单局面工具或人工事件记录工具。

1. 顶部选择场风、局数、庄家、本场、供托，可填随机种子；展开规则设置修改开关、起点或四家点数，再按“新建单局”。新建会替换未保存的内存局面，当前局规则不可中途修改。
2. 四个区域展示四家手牌/牌背、牌河、已成立组、来源玩家、点数及立直。被鸣走的历史弃牌用斜线标记；每个牌区可以滚动。
3. 下方是“操作玩家”的手牌。点击手牌选中对应弃牌，然后按“执行所选动作”；动作下拉框也提供吃碰杠、立直、自摸、荣和、过及九种九牌。吃碰组合明确列出牌码，包含赤牌选择。
4. 响应阶段逐家操作，荣和优先且允许多家。没有合法响应的玩家自动跳过；没有待选动作时自动进入下一次摸牌。
5. “分析视角”独立于操作玩家。右侧分析始终来自该玩家的可见记录；完整模拟历史下的牌效推荐会排除食替、立直锁定等禁止弃牌。
6. “全知调试显示”仅揭示当前牌桌手牌，不改变分析请求；历史回放始终使用当时玩家视角。
7. “测试推进一步”及“自动测试”采用和牌优先，否则过/摸切的简单驱动。它用于检查连续流程，不会主动尝试所有鸣牌，更不是何切策略；可随时停止，人工选择鸣牌。
8. 点击右侧可见事件进入只读回放，“回到最新”恢复操作；“撤销动作”重放至上一提交动作，包含其自动产生的事件。
9. 保存的是全知模拟文件，不能拿来直接作为分析或训练输入。需要覆盖已有文件时勾选允许覆盖。加载会按文件内规则完整重放；格式与人工记录文件不同。
10. 结束后查看结算区域的役种、番符、支付和下一局场况；本版不自动开下一局。勾选“实际输入/输出 JSON”可同时查看分析两端的真实对象。
11. 分析方法选择 `fixed-v2` 可看综合/进攻/防守偏好；“v2 权重 JSON”输入如 `{"risk":12,"value":2}` 后点“应用”，`{}` 使用默认。只修改分析权重，不改变模拟规则。分项在实际输出 JSON 中，权重含义与限制见 [v2 说明](../docs/fixed-v2.md)。

规则与程序接口见[模拟器说明](../docs/simulator.md)。桌面交互检查：`python -m simulator_ui.smoke`。原 `test_ui/` 源码未改动。
