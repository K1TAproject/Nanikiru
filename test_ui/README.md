# 单局面牌效测试工具

这是新建的独立测试 UI，不恢复旧 Game、Recorder 或界面。不推进对局、不保存记录。

## 启动

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m test_ui
```

也可在 IDE 中以项目 `.venv` 解释器运行根目录 `run_position_ui.py`。仅使用标准库 Tkinter，分析核心不导入 UI，不增加运行依赖。

## 操作

- **随机换一手**：从每门一赤的 136 枚实体库存随机抽取 13 张手牌、1 张摸牌、1 张宝牌指示牌。只将这 15 枚可见牌交给分析，不保留真实牌山或对手暗手。
- **自行组牌**：勾选后，在原窗口展开全部 37 种牌码的图形选牌区。先点上方手牌、摸牌或指示牌选定替换目标，再点牌种；每次替换立即理牌并重算。可以逐张组成任意符合库存的牌形。
- 灰色牌种表示除目标牌以外的库存已用完，不能再选。同类最多四枚；每门赤五一枚、普通五三枚，指示牌也占库存。
- **所选弃牌分析**：点击任意一张手牌或摸牌，左区显示切出该牌后的向听、进张种类和未见枚数。0 向听显示为听牌。点击不是实际弃牌，原手牌继续显示。
- **最小牌效推荐**：右区显示第一名候选；先最小向听、再最大未见进张数，相同则并列。相同牌码合并展示数量，赤五不与普通五合并。点推荐牌可查看对应分析。
- **载入听牌示例**：切九万后 0 向听；三索/六索各未见三枚，共六枚，六索指示牌已计入已见库存。

手牌 13 张保持一行且自动理牌，摸进第 14 张单独放置。选牌区、手牌、弃牌分析、推荐都在同一窗口不同位置，无页面跳转或弹出分析窗口。结果较多时用各区滚动条查看。

## 图形与范围

牌面由本项目 Canvas 图形绘制：筒子圆点、索子/一索鸟形、万字和字牌，赤五有红色区分。可在 [assets/mahjong](../assets/mahjong/README.md) 放入 PNG 替换，无需依赖网络或等待图片素材。

测试局面固定假设：门清、未立直、普通摸牌后，没有食替限制；除手牌与一张指示牌外，没有其他公开牌。它是独立牌形实验，不能拿来代替任意真实中盘局面的完整记录。

排序是一步牌效启发式，不评估役、宝牌价值、打点、多步改良或防守。宝牌指示牌目前只影响已见库存。未见枚数不等于活牌山剩余数量，也不是和牌概率。排序不赋予候选 `allowed`，不写入可执行 recommendations。

```powershell
.\.venv\Scripts\python.exe -m test_ui.smoke
```
